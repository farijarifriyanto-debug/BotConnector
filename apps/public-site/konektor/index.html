Konektor

Konektor untuk workflow event-driven.

Sambungkan kejadian di BotConnector (transaksi masuk, stok berubah, kendaraan keluar) ke tindakan di sistem lain. Konektor aktif bisa langsung dipakai; yang lain tetap bisa diakses lewat webhook/API sebagai jalur universal.

Tersedia
WHTersedia

Webhook

Terima event JSON lewat HTTPS dari aplikasi, form, server, atau sistem Anda sendiri.

APITersedia

HTTP / API

Teruskan data workflow ke endpoint HTTPS mana pun menggunakan request API.

TGTersedia

Telegram

Kirim alert dan notifikasi workflow ke chat atau grup Telegram.

GSTersedia

Google Sheets

Jadikan perubahan data spreadsheet sebagai pemicu atau tujuan workflow.

WASegera Hadir

WhatsApp

Kanal messaging untuk workflow pelanggan dan notifikasi bisnis.

PAYSegera Hadir

Payment Gateway

Gunakan perubahan status transaksi sebagai pemicu workflow bisnis.

Mulai dari trigger, tentukan tindakan, uji alur, lalu aktifkan saat sudah siap.
