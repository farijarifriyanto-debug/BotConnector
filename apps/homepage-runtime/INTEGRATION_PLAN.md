# Integration plan — Personal Automation v0.8

1. Pertahankan `/personal` sebagai landing page publik.
2. Hubungkan tombol Mulai dan Masuk ke Production Auth.
3. Setelah login, simpan pilihan modul Creator, Freelancer, atau keduanya.
4. Creator Assistant:
   - AI generation.
   - Draft storage.
   - Content calendar.
   - Approval sebelum publikasi.
5. Freelancer Assistant:
   - Client pipeline.
   - Project and revision store.
   - Document renderer.
   - Invoice and payment reminder.
6. Jangan menjalankan posting, pengiriman proposal, invoice, atau reminder
   tanpa persetujuan pengguna.
