Kebijakan Privasi BotConnector

Terakhir diperbarui: Agustus 2026

1. Pengumpulan Data

Kami mengumpulkan data yang Anda berikan secara langsung saat mendaftar, menggunakan layanan, atau menghubungi kami.

2. Penggunaan Data

Data digunakan untuk menyediakan, memelihara, dan meningkatkan layanan kami, serta untuk keamanan dan kepatuhan hukum.

3. Berbagi Data

Kami tidak menjual data pribadi Anda. Data hanya dibagikan kepada penyedia layanan tepercaya dan sesuai hukum.

4. Hak Anda

Anda memiliki hak untuk mengakses, memperbaiki, menghapus, atau membatasi pemrosesan data pribadi Anda.

5. Keamanan

Kami menerapkan langkah keamanan teknis dan organisasional untuk melindungi data Anda.

6. Kontak Privasi

Untuk pertanyaan atau permintaan terkait privasi, silakan kirim melalui:

  • Formulir Permintaan Privasi: /support?category=privacy
    • {% if not mailbox_provisioning_required %}
  • Email: privacy@botconnector.id
    • {% else %}
  • Email: privacy@botconnector.id (provisioning diperlukan)
    • {% endif %}

Permintaan privasi termasuk: akses data, koreksi, penghapusan, konsent, dan pertanyaan privasi lainnya.
