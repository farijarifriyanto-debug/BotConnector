Keamanan BotConnector

Terakhir diperbarui: Agustus 2026

Praktik Keamanan

Kami menerapkan enkripsi, autentikasi multi-faktor, dan pemantauan keamanan berkelanjutan.

Laporan Kerentanan

Jika Anda menemukan masalah keamanan, silakan laporkan melalui saluran resmi kami:

  • Formulir Laporan Keamanan: /support/security-report atau /support?category=security
    • {% if not mailbox_provisioning_required %}
  • Email: security@botconnector.id
    • {% else %}
  • Email: security@botconnector.id (provisioning diperlukan)
    • {% endif %}
Panduan: Identifikasi layanan yang terdampak, deskripsikan perilaku yang dapat direproduksi, hindari mengirim credential rahasia, dan jangan lakukan pengujian destruktif terhadap data pengguna lain.

Kami tidak menjalankan program bug bounty resmi atau menawarkan hadiah uang saat ini.

Standar Keamanan

Platform kami mengikuti praktik terbaik industri termasuk OWASP Top 10, enkripsi TLS 1.2+, dan audit keamanan berkala.

Keamanan Data

Data pengguna disimpan dengan enkripsi saat transit dan diam. Akses dibatasi berdasarkan prinsip least privilege.
